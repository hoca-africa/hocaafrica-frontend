# Hoca-Africa
Welcome to Hoca Africa! A modern web application built with Next.js and deployed on Vercel.

# 🌐 Live Site
Visit us at: https://hoca-africa.org

#  About
Hoca is a Home Care Alliance Africa (HOCA-A) is a Pan-African, not-for-profit alliance dedicated to developing systems, standards, and regulatory frameworks for home-based and geriatric care across the continent.

# Getting Started
Prerequisites

Node.js 16.x or higher
npm or yarn package manager

Installation

Clone the repository:

git clone https://github.com/HocaAfrica/Hocaa-frontend.git
cd hoca-africa

Install dependencies:

npm install

 or

yarn install

Create a .env.local file (if needed) and add your environment variables:

# Add your environment variables here
Development
Run the development server:
npm run dev

 or

yarn dev
Open http://localhost:3000 in your browser to see the result.

# 📁 Project Structure
hoca-africa/
├── pages/ # Next.js pages and API routes
├── components/ # React components
├── styles/ # CSS and styling
├── public/ # Static assets
├── lib/ # Utility functions and helpers
└── package.json # Project dependencies
🛠️ Building & Deployment
Build for production:
npm run build

 or

yarn build
Start production server:
npm start

 or

yarn start

# Deployment
This project is deployed on Vercel. Any push to the main branch automatically triggers a new deployment.
Domain: hoca-africa.org (previously hosted on Hostgator as a WordPress site, now running on Next.js)

# Technologies Used
